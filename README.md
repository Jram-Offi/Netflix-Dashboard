# 🎬 Netflix Data Analysis Dashboard

A comprehensive data analysis and visualization dashboard built using **Python, Pandas, NumPy, Matplotlib, and Seaborn** to explore and analyze Netflix content data.

## 📌 Project Overview

This project performs data cleaning, preprocessing, statistical analysis, and visualization on the Netflix Titles dataset. The dashboard provides insights into content distribution, release trends, genres, ratings, and country-wise contributions through multiple charts displayed in a single interactive dashboard layout.

## 🚀 Features

* Data Cleaning and Preprocessing
* Missing Value Handling
* Duplicate Record Removal
* Statistical Summary Generation
* Multi-Visualization Dashboard
* Content Distribution Analysis
* Genre Analysis
* Country-wise Analysis
* Rating Analysis
* Release Year Trends
* Dashboard Summary Panel

## 📊 Dashboard Visualizations

### 1. Movies vs TV Shows

Displays the count comparison between Movies and TV Shows available on Netflix.

### 2. Top 10 Countries

Shows the countries contributing the most content to Netflix.

### 3. Top Ratings

Analyzes the most common content ratings.

### 4. Content Growth by Year

Visualizes Netflix content growth across release years.

### 5. Top Genres

Displays the most popular genres available on Netflix.

### 6. Content Percentage

Pie chart showing the percentage distribution of Movies and TV Shows.

### 7. Top Release Years

Highlights years with the highest content releases.

### 8. Top 5 Countries Share

Country contribution percentage visualization.

### 9. Project Summary

Provides:

* Total Records
* Total Movies
* Total TV Shows
* Average Release Year
* Most Common Rating

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/netflix-data-analysis-dashboard.git
```

Navigate to the project folder:

```bash
cd netflix-data-analysis-dashboard
```

Install required packages:

```bash
pip install pandas numpy matplotlib seaborn
```

Run the project:

```bash
python netflix_dashboard.py
```
